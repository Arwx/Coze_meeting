## 会议背景

新系统需要提供用户、权限、业务配置、文件处理和异步任务能力。会议围绕 Node.js、Java、Python 三类后端技术栈进行比较。

## 讨论内容

1. Node.js 方案

   NestJS 具备模块化、依赖注入、装饰器和良好的 TypeScript 支持，适合与前端共享类型。缺点是 CPU 密集任务需要额外拆分。

2. Java 方案

   Spring Boot 生态成熟，适合复杂企业系统。团队维护经验较多，但启动成本和模板代码相对更重。

3. Python 方案

   FastAPI 开发效率高，适合 AI 和数据处理场景。若系统主体为业务管理后台，团队认为 Python 更适合作为独立 AI 服务。

4. 服务拆分

   一期不做微服务，采用模块化单体。AI 任务和文件解析保留独立服务接口的可能性。

## 关键结论

- 后端主框架采用 NestJS。
- 语言统一使用 TypeScript。
- 项目采用模块化单体架构。
- 文件解析和 AI 能力通过独立模块封装，后续可拆服务。
- 接口文档使用 OpenAPI 生成。
