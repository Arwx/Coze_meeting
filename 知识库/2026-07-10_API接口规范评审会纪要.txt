## 会议背景

前后端即将进入联调阶段，需要统一接口路径、请求格式、错误结构、分页规则和版本管理方式，减少沟通成本。

## 讨论内容

1. REST 风格

   接口采用 REST 风格，资源使用复数名词。复杂业务动作允许使用明确动词，例如 `/imports/:id/retry`。

2. 返回结构

   成功响应直接返回数据对象。错误响应统一返回 `code`、`message`、`details`、`requestId`。

3. 分页规则

   列表接口默认使用 `page` 和 `pageSize`。大数据量场景后续再考虑 cursor 分页。

4. 权限错误

   未登录返回 401，无权限返回 403，资源不存在返回 404，参数错误返回 400。

5. 接口文档

   后端通过 OpenAPI 自动生成接口文档，前端基于文档生成类型或进行校验。

## 关键结论

- API 前缀统一为 `/api/v1`。
- 时间字段统一使用 ISO 8601 字符串。
- 错误响应必须包含 `requestId`。
- 列表接口返回 `items` 和 `total`。
- 参数校验错误需要返回字段级错误信息。
